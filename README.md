## The pitch

> StillHere gives anxious homeowners hourly confirmation that their house is still at the same address, with premium alerts if we check twice and a monthly report proving it has not moved.

One sentence, 186 characters. An app that solves a problem nobody has — reassuring you that your house has not moved — with deadpan-absurd monetization on top: pay extra for us to check twice.

## How it works

`main.py` (Python 3.13, standard library only) writes the pitch line to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default), exactly, with no trailing newline.
